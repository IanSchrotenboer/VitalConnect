# Logo Vital Connect

Een figuurtje dat opstaat naar de zon: de zon (oker) is het hoofd, de armen en het blad zijn de drie kleuren van de dagringen in de app (abrikoos, zeegroen, indigo), op het dennengroen van de wijzerplaat. Gebaseerd op de opzet uit ChatGPT, vlak gemaakt en in de kleuren van de app.

| Bestand | Gebruik |
|---|---|
| `logo.svg` | Vierkant logo, bron voor alle PNG's |
| `logo-afgerond.svg` | Met ronde hoeken: website (favicon) en documenten |
| `beeldmerk.svg` | Alleen het figuurtje, transparant, voor op een donkere achtergrond |
| `logo-120.png` | Google Cloud → Google Auth Platform → Branding (120 × 120) |
| `logo-512.png` | Play Store-icoon (ook in `play-store/grafisch/icoon-512.png`) |
| `logo-1024.png` | App Store (iPhone-app) en drukwerk |

In de Android-app: `res/drawable/ic_launcher_foreground.xml` (kleur), `ic_launcher_monochrome.xml` (themed icons, Android 13+) en `logo_mark.xml` (inlogscherm). Kleuren: achtergrond `#123430`, zon `#DDB15A`, abrikoos `#F5935A`, zeegroen `#4CC3B3`, indigo `#8C97F2`.
