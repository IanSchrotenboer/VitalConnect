Wat een echte koppeling vraagt

Garmin Connect
Garmin Connect Developer Program met OAuth 2.0. Zakelijke toegang vraagt goedkeuring; voor je eigen data bestaat een persoonlijke API-sleutel.
Suunto app
Suunto Cloud API via het partnerprogramma (API Zone). Levert trainingen als FIT-bestanden; niet bedoeld voor persoonlijk gebruik.
Google Health
Google Health API voor clouddata van Fitbit- en Google-apparaten. In een Android-app komt daar Health Connect bij, met data op het toestel.
Google Fit
De Fit-API's worden ondersteund tot eind 2026. Nieuwe koppelingen lopen via Google Health API of Health Connect.
